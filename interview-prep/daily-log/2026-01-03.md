# Daily Interview Prep — January 03, 2026

Five questions worked through this session.

---

### Q1. How do balanced BSTs (AVL / red-black) stay balanced?

**Answer.** AVL enforces height difference <= 1 via rotations after inserts/deletes — tighter, better for search. Red-black allows larger imbalance but uses at most 2 rotations per insert, so it's favored when insert/delete dominate (e.g., Java TreeMap, Linux CFS).

---

### Q2. What is a sliding window and what does it solve?

**Answer.** Maintain [left, right) over an array with O(1) amortized adds/removes from the ends. Solves fixed-size window max/sum, and variable-size problems like 'longest substring without repeating chars' by shrinking when the constraint breaks.

---

### Q3. Explain quicksort and its worst case.

**Answer.** Pick a pivot, partition around it, recurse. Average O(n log n), in-place, cache-friendly. Worst case O(n^2) on sorted input with naive first/last pivot — fixed by randomized or median-of-three pivot. It's not stable.

---

### Q4. Why is merge sort O(n log n) always, and what does it cost?

**Answer.** It splits in half (log n levels) and each level merges in O(n). Guarantees n log n regardless of input and is stable, but needs O(n) auxiliary space — that's the cost.

---

### Q5. What is a count sort / radix sort and when is it valid?

**Answer.** Counting sort buckets by integer value in O(n + k) — linear when k is bounded, so it beats comparison sort's n log n floor. Radix sort generalizes it digit-by-digit. Only works on bounded integers (or fixed-length keys).

---

### Q6. What is dynamic programming, and what makes a problem solvable with it?

**Answer.** Break a problem into overlapping subproblems, solve each once, store the result (memoization/table). Requirements: optimal substructure (optimal solution built from optimal sub-solutions) and overlapping subproblems. Example: Fibonacci, knapsack, longest common subsequence.

---

### Q7. Memoization vs tabulation?

**Answer.** Memoization is top-down recursion with a cache; tabulation is bottom-up iteration filling a table. Same complexity; tabulation removes recursion overhead and can enable space reduction (keep only the last 2 rows), while memoization is often easier to derive from the recurrence.

---

### Q8. What is backtracking?

**Answer.** Build a solution incrementally, and prune the branch as soon as a constraint is violated. Exploring all valid arrangements (N-queens, Sudoku, permutations, subsets) with pruning. Key: make a choice, recurse, undo the choice.

---

### Q9. Explain Kadane's algorithm.

**Answer.** For maximum subarray sum: track best ending here = max(x, best ending here + x) and the global best. Single pass, O(n), O(1) space. The insight is that a negative prefix can never help a future subarray.

---

### Q10. What is topological sort and where is it used?

**Answer.** Ordering the nodes of a DAG so every edge points forward. Computed via Kahn's algorithm (BFS on in-degrees) or DFS finishing times. If a cycle remains, the sort is impossible — which is itself useful for cycle detection. Used in build systems, task scheduling, course prerequisites.

---

### Q11. Greedy vs DP — how do you decide?

**Answer.** Greedy makes the locally best choice and never revisits it — only valid when the greedy-choice property and optimal substructure both hold (interval scheduling, Huffman coding, coin change with canonical coins). DP is the safe general method when subproblems overlap and local choices matter.

---

### Q12. What is A* search?

**Answer.** Best-first search over a graph with cost = g(n) (cost so far) + h(n) (heuristic estimate to goal). With an admissible (never overestimating) heuristic it finds the optimal path; h = 0 reduces to Dijkstra, h = g reduces to greedy best-first. Used in pathfinding and game AI.

---

### Q13. Explain the divide and conquer pattern.

**Answer.** Split the problem into independent subproblems, solve each recursively, combine the results. The recurrence is T(n) = aT(n/b) + O(n^d); the Master Theorem compares a/b^d to decide the bound. Examples: merge sort, matrix multiplication, closest pair.

---

### Q14. How do you find the kth largest element faster than sorting?

**Answer.** Quickselect: partition like quicksort but recurse only into the side containing the kth element — average O(n), worst O(n^2) (fix with median-of-medians pivot or randomization). Or a size-k min-heap: O(n log k), which wins when k << n.

---

### Q15. What is the difference between BFS and Dijkstra on unweighted graphs?

**Answer.** On unweighted graphs Dijkstra degenerates to BFS — every relaxation has the same unit cost, so the heap never reorders anything. BFS is the simpler, faster choice there; keep Dijkstra for weighted edges.
