# Daily Interview Prep — February 06, 2026

Five questions worked through this session.

---

### Q1. Explain quicksort and its worst case.

**Answer.** Pick a pivot, partition around it, recurse. Average O(n log n), in-place, cache-friendly. Worst case O(n^2) on sorted input with naive first/last pivot — fixed by randomized or median-of-three pivot. It's not stable.

---

### Q2. Why is merge sort O(n log n) always, and what does it cost?

**Answer.** It splits in half (log n levels) and each level merges in O(n). Guarantees n log n regardless of input and is stable, but needs O(n) auxiliary space — that's the cost.

---

### Q3. What is a count sort / radix sort and when is it valid?

**Answer.** Counting sort buckets by integer value in O(n + k) — linear when k is bounded, so it beats comparison sort's n log n floor. Radix sort generalizes it digit-by-digit. Only works on bounded integers (or fixed-length keys).

---

### Q4. What do we mean when we say an algorithm is O(n log n)?

**Answer.** Runtime grows proportionally to n log n: n log n = n x log n, n x log2 n = n x 10. Big-O hides constants and lower-order terms, so 10n log n is also O(n log n). It describes the asymptotic upper bound of the worst-case behavior we analyzed.

---

### Q5. Explain the two-pointer technique.

**Answer.** Keep left and right pointers moving inward (or both moving forward) to exploit monotonic structure — sorted arrays, prefix structure, window validity. Reduces brute-force O(n^2) to O(n) for problems like two-sum on sorted arrays, container-with-most-water, and palindrome checks.

---

### Q6. What is copy-on-write and where is it used?

**Answer.** Share read-only pages between users; on first write, the kernel allocates a new page and copies, then points the writer at it. Used in fork() (child shares the parent's pages until it writes), in ZFS/Btrfs, and in persistent data structures (Clojure's atoms, Rust's Arc-based immutability patterns).

---

### Q7. What is HTTP/2 and how does it fix head-of-line blocking at one layer but create it at another?

**Answer.** Multiplexes many streams over one TCP connection with binary framing and header compression (HPACK), killing HTTP/1.1's one-request-per-connection stalls. But TCP-level retransmission still blocks all streams — that's why HTTP/3 moved to QUIC/UDP.

---

### Q8. What is a file descriptor and why is it just an integer?

**Answer.** An index into the per-process table of open file handles (socket, pipe, regular file, terminal). Everything is a stream of bytes to the kernel, so dup/pipe/redirect work uniformly — /dev/null, socket 3, and an open file all share the same syscall interface.

---

### Q9. Explain how DNS works in a few sentences.

**Answer.** The resolver queries a recursive resolver, which walks the hierarchy: root servers point to the TLD (.com) servers, which point to the authoritative nameserver for the domain, which answers the A/AAAA/CNAME record. Results are cached at every level per TTL.
