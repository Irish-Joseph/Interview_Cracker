# Daily Interview Prep — February 12, 2026

Five questions worked through this session.

---

### Q1. What is a file descriptor and why is it just an integer?

**Answer.** An index into the per-process table of open file handles (socket, pipe, regular file, terminal). Everything is a stream of bytes to the kernel, so dup/pipe/redirect work uniformly — /dev/null, socket 3, and an open file all share the same syscall interface.

---

### Q2. Explain how DNS works in a few sentences.

**Answer.** The resolver queries a recursive resolver, which walks the hierarchy: root servers point to the TLD (.com) servers, which point to the authoritative nameserver for the domain, which answers the A/AAAA/CNAME record. Results are cached at every level per TTL.

---

### Q3. What is the difference between a signal and an exception?

**Answer.** A signal is an asynchronous OS-level interrupt delivered to a process/thread (SIGTERM, SIGKILL, SIGSEGV); a process can install handlers or ignore it, but SIGKILL/SIGSTOP cannot be caught. An exception is a synchronous, in-language control flow mechanism for errors at a known instruction.

---

### Q4. What is the CAP theorem and what do real systems choose?

**Answer.** A distributed system cannot simultaneously guarantee Consistency, Availability, and Partition tolerance — and partitions happen, so the real choice is CP (refuse requests during a partition, e.g. ZooKeeper) or AP (serve stale data, e.g. DynamoDB).

---

### Q5. How does a load balancer work and what are the common algorithms?

**Answer.** It front-ends a pool of servers and routes each connection using round-robin, least-connections, or consistent hashing (minimizes cache invalidation when nodes change). L4 operates on IP/TCP; L7 inspects HTTP (path, headers) and can add TLS termination, retries, and rate limiting.

---

### Q6. How do you handle being stuck on a coding problem for 30 minutes?

**Answer.** Say what you've tried and what specifically is blocking, then ask for a nudge (interviewers expect this — silent spinning loses the round). If unsupervised: re-derive from a smaller case, brute-force first then optimize, and always communicate the partial solution and its complexity.

---

### Q7. What does code review actually check for, from a reviewer's view?

**Answer.** Correctness (does it do the spec?), clarity (naming, structure, dead code), tests (are the important paths covered?), and risk (failure modes, rollback, migration safety). As a reviewer, you're also judging the diff's size — a 3000-line PR is itself a process smell worth flagging.

---

### Q8. Tell me about a time you improved a slow system.

**Answer.** Lead with measurement: what the metric was (p99 latency, throughput), how you found the bottleneck (profiling, slow-query log, flamegraph), the fix, and the before/after numbers. 'I added a cache' without the diagnosis story is the answer that loses senior rounds.

---

### Q9. How do you prioritize when everything is urgent?

**Answer.** Impact x urgency vs effort, but first verify the urgency is real (a 'production is down' that's actually a 2% error rate is different). Make the tradeoff explicit to stakeholders rather than silently absorbing it, and leave room for the actual fire when it lands. Then describe how you communicate the deferral.

---

### Q10. What is the difference between a stack and a queue?

**Answer.** A stack is LIFO — push/pop both happen at the same end; a queue is FIFO — enqueue at the back, dequeue from the front. Stacks model undo, call frames, backtracking; queues model task scheduling, BFS, rate limiting.

---

### Q11. Why does a hash table give O(1) average lookup?

**Answer.** The key is passed through a hash function to index the bucket directly, skipping the scan. It degrades to O(n) when collisions cluster (poor hash or load factor too high), so implementations resize at ~0.7 load and use chaining or open addressing.

---

### Q12. What is a binary search tree and when does it degrade?

**Answer.** A BST keeps left < node < right, giving O(log n) search/insert on average. It degrades to O(n) when the tree becomes a chain (sorted insertions), which is why balanced variants (AVL, red-black) exist.
