# Daily Interview Prep — February 26, 2026

Five questions worked through this session.

---

### Q1. What is the difference between BFS and Dijkstra on unweighted graphs?

**Answer.** On unweighted graphs Dijkstra degenerates to BFS — every relaxation has the same unit cost, so the heap never reorders anything. BFS is the simpler, faster choice there; keep Dijkstra for weighted edges.

---

### Q2. When would you use BFS on an adjacency list vs matrix?

**Answer.** Adjacency list: O(V + E) memory, ideal for sparse graphs (the common case). Matrix: O(V^2) memory but O(1) edge-existence checks and easy to combine with matrix operations — fine for dense graphs or small V with repeated queries.

---

### Q3. Process vs thread?

**Answer.** A process is an isolated execution with its own address space and file handles; a thread is a unit of execution inside a process sharing that address space. Threads are cheap to create and communicate via shared memory (at the cost of synchronization); processes are isolated by default and talk via IPC.

---

### Q4. What is virtual memory?

**Answer.** Each process sees a private address space backed by the MMU, which maps virtual pages to physical frames via page tables. It gives isolation, overcommit (map more than RAM), lazy allocation, and the foundation for demand paging and copy-on-write fork.

---

### Q5. TCP vs UDP?

**Answer.** TCP: connection-oriented, reliable, in-order delivery with retransmission, flow and congestion control — for HTTP, databases. UDP: connectionless, no ordering or retransmit, tiny header — for video, DNS, game state, where a late packet is worse than a lost one. QUIC layers reliable streams over UDP.

---

### Q6. What is the GIL in CPython?

**Answer.** A global interpreter lock that lets only one thread execute Python bytecode at a time, protecting refcounts. It serializes CPU-bound Python threads, so you use multiprocessing for CPU work and threads still help for I/O (the lock is released during blocking calls).

---

### Q7. What is a memory leak?

**Answer.** Memory that is no longer reachable through any pointer but was never freed (or is kept alive by an unintended reference). Symptoms: slow RSS growth, eventual OOM. Sources: unremoved listeners/cache entries, reference cycles (in refcounted runtimes without GC), leaked native handles.

---

### Q8. Explain reference counting vs tracing garbage collection.

**Answer.** Refcounting frees an object the moment its count hits zero — simple and immediate, but cannot collect cycles and the per-pointer overhead is real. Tracing GC (mark-and-sweep, generational, e.g. G1/ZGC) scans from roots, handles cycles, but introduces pauses or pauses-hiding (ZGC uses colored pointers for concurrent collection).

---

### Q9. What is copy-on-write and where is it used?

**Answer.** Share read-only pages between users; on first write, the kernel allocates a new page and copies, then points the writer at it. Used in fork() (child shares the parent's pages until it writes), in ZFS/Btrfs, and in persistent data structures (Clojure's atoms, Rust's Arc-based immutability patterns).

---

### Q10. What is HTTP/2 and how does it fix head-of-line blocking at one layer but create it at another?

**Answer.** Multiplexes many streams over one TCP connection with binary framing and header compression (HPACK), killing HTTP/1.1's one-request-per-connection stalls. But TCP-level retransmission still blocks all streams — that's why HTTP/3 moved to QUIC/UDP.

---

### Q11. What is a file descriptor and why is it just an integer?

**Answer.** An index into the per-process table of open file handles (socket, pipe, regular file, terminal). Everything is a stream of bytes to the kernel, so dup/pipe/redirect work uniformly — /dev/null, socket 3, and an open file all share the same syscall interface.

---

### Q12. Explain how DNS works in a few sentences.

**Answer.** The resolver queries a recursive resolver, which walks the hierarchy: root servers point to the TLD (.com) servers, which point to the authoritative nameserver for the domain, which answers the A/AAAA/CNAME record. Results are cached at every level per TTL.

---

### Q13. What is the difference between a signal and an exception?

**Answer.** A signal is an asynchronous OS-level interrupt delivered to a process/thread (SIGTERM, SIGKILL, SIGSEGV); a process can install handlers or ignore it, but SIGKILL/SIGSTOP cannot be caught. An exception is a synchronous, in-language control flow mechanism for errors at a known instruction.

---

### Q14. What is the CAP theorem and what do real systems choose?

**Answer.** A distributed system cannot simultaneously guarantee Consistency, Availability, and Partition tolerance — and partitions happen, so the real choice is CP (refuse requests during a partition, e.g. ZooKeeper) or AP (serve stale data, e.g. DynamoDB).

---

### Q15. How does a load balancer work and what are the common algorithms?

**Answer.** It front-ends a pool of servers and routes each connection using round-robin, least-connections, or consistent hashing (minimizes cache invalidation when nodes change). L4 operates on IP/TCP; L7 inspects HTTP (path, headers) and can add TLS termination, retries, and rate limiting.
