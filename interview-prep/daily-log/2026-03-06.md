# Daily Interview Prep — March 06, 2026

Five questions worked through this session.

---

### Q1. What is a deadlock in a database and how do DBs handle it?

**Answer.** Two transactions each lock rows the other needs (T1 locks A waits for B; T2 locks B waits for A). MySQL InnoDB detects via a wait-for graph and kills the victim (ER_LOCK_DEADLOCK); PostgreSQL waits up to deadlock_timeout then detects and aborts one transaction. App fix: consistent lock ordering, short transactions, retry with backoff.

---

### Q2. What are dirty, non-repeatable and phantom reads?

**Answer.** Dirty read: reading another transaction's uncommitted data (lost if it rolls back). Non-repeatable read: re-reading a committed row that another committed transaction changed. Phantom read: a re-run of a range query returns new rows inserted by another committed transaction. Each maps to the isolation levels above.

---

### Q3. How does a JOIN actually execute?

**Answer.** The planner picks a strategy: nested loop (probe inner per outer row — good with cheap indexes or tiny outer), hash join (build a hash of the smaller side, probe with the larger — the default for large unindexed joins), or merge join (both sides sorted on the key — good for ranges). EXPLAIN shows which one and its estimated cost.

---

### Q4. What is an ORM and what are its classic performance problems?

**Answer.** A library mapping objects to tables (SQLAlchemy, Hibernate). Classic problems: the N+1 query (looping entities and loading each relation lazily — fix with eager join/IN batch), over-fetching with big eager graphs, writing the whole object back (lost updates on concurrent writes), and hiding the SQL you actually shipped.

---

### Q5. What is a foreign key and does it always need an index?

**Answer.** A constraint declaring that a column's values must exist in the parent table's key, with cascade options (RESTRICT/NO ACTION, CASCADE, SET NULL). Most DBs automatically index FK columns (PostgreSQL does; MySQL InnoDB does) because the check needs it — don't assume, check the catalog.

---

### Q6. What is a context switch and what does it cost?

**Answer.** The OS saving the current thread's CPU state (registers, PC, stack pointer) to its PCB and restoring another thread's. Costs a few microseconds plus cache/TLB pollution — millions of involuntary switches per second can dominate runtime, which is why thread pools exist.

---

### Q7. Explain TCP three-way handshake and why three packets?

**Answer.** Client SYN(seq=x) -> server SYN-ACK(seq=y, ack=x+1) -> client ACK(ack=y+1). Three packets ensure both sides' send and receive paths work and both initial sequence numbers are exchanged. Two would leave one direction unconfirmed and allows stale duplicated SYNs to open connections.

---

### Q8. What is the GIL in CPython?

**Answer.** A global interpreter lock that lets only one thread execute Python bytecode at a time, protecting refcounts. It serializes CPU-bound Python threads, so you use multiprocessing for CPU work and threads still help for I/O (the lock is released during blocking calls).

---

### Q9. What is a memory leak?

**Answer.** Memory that is no longer reachable through any pointer but was never freed (or is kept alive by an unintended reference). Symptoms: slow RSS growth, eventual OOM. Sources: unremoved listeners/cache entries, reference cycles (in refcounted runtimes without GC), leaked native handles.

---

### Q10. Explain reference counting vs tracing garbage collection.

**Answer.** Refcounting frees an object the moment its count hits zero — simple and immediate, but cannot collect cycles and the per-pointer overhead is real. Tracing GC (mark-and-sweep, generational, e.g. G1/ZGC) scans from roots, handles cycles, but introduces pauses or pauses-hiding (ZGC uses colored pointers for concurrent collection).

---

### Q11. What is copy-on-write and where is it used?

**Answer.** Share read-only pages between users; on first write, the kernel allocates a new page and copies, then points the writer at it. Used in fork() (child shares the parent's pages until it writes), in ZFS/Btrfs, and in persistent data structures (Clojure's atoms, Rust's Arc-based immutability patterns).

---

### Q12. What is HTTP/2 and how does it fix head-of-line blocking at one layer but create it at another?

**Answer.** Multiplexes many streams over one TCP connection with binary framing and header compression (HPACK), killing HTTP/1.1's one-request-per-connection stalls. But TCP-level retransmission still blocks all streams — that's why HTTP/3 moved to QUIC/UDP.

---

### Q13. What is a file descriptor and why is it just an integer?

**Answer.** An index into the per-process table of open file handles (socket, pipe, regular file, terminal). Everything is a stream of bytes to the kernel, so dup/pipe/redirect work uniformly — /dev/null, socket 3, and an open file all share the same syscall interface.
