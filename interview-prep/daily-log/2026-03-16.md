# Daily Interview Prep — March 16, 2026

Five questions worked through this session.

---

### Q1. What is a deadlock and what are its conditions?

**Answer.** Two or more threads each hold a resource the other needs, so none can proceed. Needs four conditions (Coffman): mutual exclusion, hold-and-wait, no preemption, circular wait. Break any one — common practice: impose a global lock ordering to kill circular wait, or use try-lock with timeout/backoff.

---

### Q2. What is a context switch and what does it cost?

**Answer.** The OS saving the current thread's CPU state (registers, PC, stack pointer) to its PCB and restoring another thread's. Costs a few microseconds plus cache/TLB pollution — millions of involuntary switches per second can dominate runtime, which is why thread pools exist.

---

### Q3. Explain TCP three-way handshake and why three packets?

**Answer.** Client SYN(seq=x) -> server SYN-ACK(seq=y, ack=x+1) -> client ACK(ack=y+1). Three packets ensure both sides' send and receive paths work and both initial sequence numbers are exchanged. Two would leave one direction unconfirmed and allows stale duplicated SYNs to open connections.

---

### Q4. What is the GIL in CPython?

**Answer.** A global interpreter lock that lets only one thread execute Python bytecode at a time, protecting refcounts. It serializes CPU-bound Python threads, so you use multiprocessing for CPU work and threads still help for I/O (the lock is released during blocking calls).

---

### Q5. What is a memory leak?

**Answer.** Memory that is no longer reachable through any pointer but was never freed (or is kept alive by an unintended reference). Symptoms: slow RSS growth, eventual OOM. Sources: unremoved listeners/cache entries, reference cycles (in refcounted runtimes without GC), leaked native handles.

---

### Q6. Describe Dijkstra's algorithm and its limitation.

**Answer.** Greedy shortest-path from one source using a min-heap: settle the closest unsettled node, relax edges. O((V+E) log V). Fails with negative edge weights because a settled node's distance can still decrease — use Bellman-Ford there.

---

### Q7. What is dynamic programming, and what makes a problem solvable with it?

**Answer.** Break a problem into overlapping subproblems, solve each once, store the result (memoization/table). Requirements: optimal substructure (optimal solution built from optimal sub-solutions) and overlapping subproblems. Example: Fibonacci, knapsack, longest common subsequence.

---

### Q8. Memoization vs tabulation?

**Answer.** Memoization is top-down recursion with a cache; tabulation is bottom-up iteration filling a table. Same complexity; tabulation removes recursion overhead and can enable space reduction (keep only the last 2 rows), while memoization is often easier to derive from the recurrence.

---

### Q9. What is backtracking?

**Answer.** Build a solution incrementally, and prune the branch as soon as a constraint is violated. Exploring all valid arrangements (N-queens, Sudoku, permutations, subsets) with pruning. Key: make a choice, recurse, undo the choice.

---

### Q10. Explain Kadane's algorithm.

**Answer.** For maximum subarray sum: track best ending here = max(x, best ending here + x) and the global best. Single pass, O(n), O(1) space. The insight is that a negative prefix can never help a future subarray.

---

### Q11. What is topological sort and where is it used?

**Answer.** Ordering the nodes of a DAG so every edge points forward. Computed via Kahn's algorithm (BFS on in-degrees) or DFS finishing times. If a cycle remains, the sort is impossible — which is itself useful for cycle detection. Used in build systems, task scheduling, course prerequisites.

---

### Q12. Greedy vs DP — how do you decide?

**Answer.** Greedy makes the locally best choice and never revisits it — only valid when the greedy-choice property and optimal substructure both hold (interval scheduling, Huffman coding, coin change with canonical coins). DP is the safe general method when subproblems overlap and local choices matter.
