# Daily Interview Prep — March 27, 2026

Five questions worked through this session.

---

### Q1. What is a trie and when would you use one?

**Answer.** A prefix tree where the path from root spells the key. Lookup/cost is O(key length), independent of dataset size. Used for autocomplete, spell-check, IP routing, and deduplicating prefix collisions in hash tables.

---

### Q2. What does union-find (disjoint set) do?

**Answer.** It maintains groups of elements with union() and find(). Path compression + union by rank make each operation ~O(alpha(n)), effectively constant. Classic use: detecting connected components and cycles in undirected graphs.

---

### Q3. BFS vs DFS — when do you pick each?

**Answer.** BFS (queue) finds shortest unweighted paths and is level-order; DFS (stack/recursion) explores deep paths, suits topological sort, cycle detection in directed graphs, and tree traversal. DFS can also blow the stack on deep graphs — use an explicit stack if depth is unbounded.

---

### Q4. What is a skip list and why do databases use it?

**Answer.** A sorted linked list with extra 'express lanes' at higher levels, giving O(log n) expected search with much simpler, lock-friendly code than a balanced tree. LevelDB/RocksDB use it for their memtable because range scans are easy and concurrent insertion is cheap.

---

### Q5. What is a doubly linked list and what is its tradeoff?

**Answer.** Each node holds next and prev pointers, enabling O(1) removal if you have the node, and forward/backward iteration. Cost: 16 extra bytes per node and more pointer writes on mutation.

---

### Q6. What is dynamic programming, and what makes a problem solvable with it?

**Answer.** Break a problem into overlapping subproblems, solve each once, store the result (memoization/table). Requirements: optimal substructure (optimal solution built from optimal sub-solutions) and overlapping subproblems. Example: Fibonacci, knapsack, longest common subsequence.

---

### Q7. Memoization vs tabulation?

**Answer.** Memoization is top-down recursion with a cache; tabulation is bottom-up iteration filling a table. Same complexity; tabulation removes recursion overhead and can enable space reduction (keep only the last 2 rows), while memoization is often easier to derive from the recurrence.

---

### Q8. What is backtracking?

**Answer.** Build a solution incrementally, and prune the branch as soon as a constraint is violated. Exploring all valid arrangements (N-queens, Sudoku, permutations, subsets) with pruning. Key: make a choice, recurse, undo the choice.

---

### Q9. Explain Kadane's algorithm.

**Answer.** For maximum subarray sum: track best ending here = max(x, best ending here + x) and the global best. Single pass, O(n), O(1) space. The insight is that a negative prefix can never help a future subarray.
