# Daily Interview Prep — June 24, 2026

Focus: databases. 2 questions worked through this session.

---

### Q1. How would you design a short URL service (bit.ly)?

**Answer.** Hash the long URL (or use a monotonic counter / base62 of an auto-increment id) to a 7-char code — counter avoids hash collisions and is cache-friendly. Store code->URL in a KV store or sharded DB, 301 redirect (caches the mapping in browsers) or 302 if you need click analytics. Handle load with a CDN + hot-key replication.

---

### Q2. What is a write-ahead log (WAL) and why is it important?

**Answer.** Every change is appended to a durable log before being applied to the data structures; crash recovery replays the log (redo) and rolls back uncommitted work (undo). It's what makes a database durable after a power loss, and the same log powers replication, point-in-time recovery, and compaction in LSM stores.

---

### Q3. Explain a min-heap and its typical use.

**Answer.** A complete binary tree stored in an array where each parent <= its children, so the root is always the minimum. Insert/sift is O(log n); it powers priority queues, top-k problems, Dijkstra, and merge-k-sorted-lists.

---

### Q4. How does an LRU cache work?

**Answer.** A hash map from key to node plus a doubly linked list for recency. On hit, move the node to the front; on insert, evict the back. Both operations are O(1).

---

### Q5. What is a trie and when would you use one?

**Answer.** A prefix tree where the path from root spells the key. Lookup/cost is O(key length), independent of dataset size. Used for autocomplete, spell-check, IP routing, and deduplicating prefix collisions in hash tables.

---

### Q6. What does union-find (disjoint set) do?

**Answer.** It maintains groups of elements with union() and find(). Path compression + union by rank make each operation ~O(alpha(n)), effectively constant. Classic use: detecting connected components and cycles in undirected graphs.

---

### Q7. BFS vs DFS — when do you pick each?

**Answer.** BFS (queue) finds shortest unweighted paths and is level-order; DFS (stack/recursion) explores deep paths, suits topological sort, cycle detection in directed graphs, and tree traversal. DFS can also blow the stack on deep graphs — use an explicit stack if depth is unbounded.

---

### Q8. What is a skip list and why do databases use it?

**Answer.** A sorted linked list with extra 'express lanes' at higher levels, giving O(log n) expected search with much simpler, lock-friendly code than a balanced tree. LevelDB/RocksDB use it for their memtable because range scans are easy and concurrent insertion is cheap.
